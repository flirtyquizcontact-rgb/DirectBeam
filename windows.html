DirectBeam for Windows

Securely pair your Android phone with a Windows PC to send files, receive batches and browse authorized folders on your local network.

1 · Open DirectBeam

On Android, open PC Connect and start Windows Companion mode. Keep both devices on the same trusted local network.

2 · Pair securely

After installing the official desktop release, open the Windows app, locate your phone, compare the certificate verification code and enter the eight-digit pairing code shown on Android.

3 · Transfer

Drag files to send from Windows to Android, or select authorized files in Phone Library and save them to your PC. Files saved on Windows default to Downloads\DirectBeam.

Getting connected – step by step

  1. On Android, open DirectBeam → PC Connect. Check that API SESSION LIVE / PC SESSION is running. If stopped, tap START PC SESSION. Keep it running during file transfers.
  2. Connect Android and Windows to the same trusted Wi-Fi or local network.
  3. In Windows Companion, choose FIND MY PHONE. For a previously paired device, try CONNECT SAVED PHONE.
  4. For the first pairing, verify the security code shown by both devices, approve pairing on Android and enter the eight-digit code.
  5. To share documents or photos not listed, use CHOOSE PHOTOS / DOCUMENTS on Android. Only files you select become available.
  6. For ADVANCED FOLDERS, go to Android PC Connect → Protected folder browser → ADD AUTHORIZED FOLDER, choose a folder in the Android system picker, then browse that approved folder in Windows. Android may restrict selecting the entire Downloads folder or storage root.

The Windows app also provides a HOW TO CONNECT? guide for these steps.

Free transfers & optional Pro preview

Local pairing, Windows-to-Android transfers and individual downloads remain free. The Windows Companion advanced-release candidate adds:

  • Batch downloads – save multiple selected files.
  • Smart Sync – compare an approved Android category with a Windows folder, review missing/newer/conflicting items and copy without automatic deletion or overwriting.
  • Download ZIP – export selected DirectBeam PC Workspace files into one archive.
  • Advanced Folders – browse only folders explicitly authorized on Android.

Eligible new users may start a one-time five-minute Pro demonstration only after connecting their Android device and confirming. Pairing alone does not start the timer. No automatic charge occurs when the demonstration ends; Pro is an optional one-time unlock purchased in the Android app.

These advanced controls are undergoing release QA. The installer will be made available only after the final package has passed verification.

No desktop installation needed?

DirectBeam PC Connect also supports browser-based transfers over a trusted local network. Open the browser link shown on your Android phone in a browser on your PC.
